# Project: News Classification & Summarization (TF-IDF + BART)

This repository contains Jupyter notebooks and Python code for news classification and summarization experiments using TF-IDF features and BART-based summarization. Notebooks contain practical experiments and examples.

Repository language composition (approx.):
- Jupyter Notebook: 85.5%
- Python: 13.2%
- Shell: 1.3%

Contents
- Notebooks: practical experiments for classification and summarization
- Python scripts: utility functions and model wrappers

Getting started
1. Clone the repository:
   git clone https://github.com/MohammedTabarakAhmed/news-classification-summarization-tfidf-bart.git
2. Create a virtual environment and install dependencies (example):
   python -m venv venv
   source venv/bin/activate  # or `venv\Scripts\activate` on Windows
   pip install -r requirements.txt

If there is no requirements.txt, typical packages used include:
- numpy
- pandas
- scikit-learn
- torch
- transformers
- datasets

Running notebooks
- Open the notebooks in Jupyter or JupyterLab and run the cells in order.
